# Parcial Uno - Interfaz Gráficas

Este es el primer parcial de interfaz gráfica de la carrera de analista en sistemas. Aquí trabajaremos con **Java** para realizar el código y **UX/UI** para el análisis de la interfaz visual.

## Contenido

- Desarrollo de interfaz gráfica en Java
- Análisis de UX/UI
- Diseño visual y experiencia de usuario

## Requisitos

- Java JDK 11 o superior
- IDE recomendado: IntelliJ IDEA o Eclipse
